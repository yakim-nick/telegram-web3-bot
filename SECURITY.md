# Security

This bot reads public blockchain data and talks to Telegram. It holds no private keys and can
not move funds. Please read the security model in the README.

**Reporting a vulnerability:** please open a private security advisory on GitHub
("Report a vulnerability" on the Security tab) rather than a public issue.

Worth reporting: anything that makes the bot log or store message text, leak the bot token or the
RPC URL to users, sign or send a transaction, or be driven into unbounded work by one user.

**If you ever pasted a private key or seed phrase into a chat with any bot:** treat it as
compromised and move your funds to a new wallet.
